## 🎨 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio pessoal. A interface foi projetada com uma identidade visual moderna e tecnológica, utilizando:
*   **Fundo Dinâmico**: Grid com efeito radial holográfico (`radial-gradient` + linear grids).
*   **Design Futurista**: Fontes mono-espaçadas (`Fira Code` e `Share Tech`) e tons cian/azul neon (`#2cb7f2`).
*   **Totalmente Responsivo**: Adaptado para diferentes resoluções de telas.
*   **Seções de Navegação**:
    *   `./sobre` - Sobre mim e jornada como desenvolvedor.
    *   `./habilidades` - Minhas competências técnicas.
    *   `./projetos` - Projetos práticos e contribuições.
    *   `./contato` - Canais diretos para comunicação.

## 🚀 Como Executar o Projeto Localmente

Siga as instruções abaixo para rodar o portfólio na sua máquina local:

### Pré-requisitos
Certifique-se de ter o **[Node.js](https://nodejs.org/)** instalado em sua máquina.

### Passo a Passo

1. **Clonar o Repositório**
   ```bash
   git clone https://github.com/Luizfelixdev/devportifolio.git
   ```

2. **Acessar a Pasta do Projeto**
   ```bash
   cd devportifolio
   ```

3. **Instalar as Dependências**
   ```bash
   npm install
   ```

4. **Iniciar o Servidor de Desenvolvimento**
   ```bash
   npm run dev
   ```

5. **Acessar no Navegador**
   O Vite irá gerar um endereço local (geralmente `http://localhost:5173`). Abra esse link para ver o portfólio rodando.
